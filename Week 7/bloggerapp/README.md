# Blogger App - React Conditional Rendering Demo

A React application showcasing 35+ conditional rendering techniques across three components.

## Quick Start

```bash
# Navigate to project
cd bloggerapp

# Install dependencies
npm install

# Start development server
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

## What You'll See

### 📚 Book Details
- Toggle book visibility
- Filter by category (React, Angular, Database, etc.)
- Search functionality
- Special offer badges for expensive books
- Dynamic pricing tiers

### 📝 Blog Details  
- Loading spinner simulation
- Error handling demo
- Featured blog filtering
- Author search
- Expandable content
- Read time indicators

### 🎓 Course Details
- Three view modes: Grid, List, Calendar
- Level filtering (Beginner, Intermediate, Advanced)
- Course completion status
- Interactive hover effects
- Course statistics

## Conditional Rendering Techniques

| Technique | Example |
|-----------|---------|
| If-else with early return | Hide/show entire components |
| Ternary operators | Dynamic button text |
| Logical AND (&&) | Conditional badges |
| Array mapping | Dynamic list rendering |
| useMemo | Expensive computations |
| Loading states | Skeleton screens |
| Error boundaries | Error handling |
| Render props | Conditional components |
| Higher-Order Components | Component wrapping |
| Context API | State management |

## Troubleshooting

If you encounter issues:

1. **Port already in use**: Try `npm start -- --port 3001`
2. **Dependencies**: Run `npm install` again
3. **Cache issues**: Clear browser cache or use incognito mode
